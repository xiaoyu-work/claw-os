# desktop — claw-os desktop environment build + runtime dependencies.
#
# Target distro: Debian 13 "trixie" (kernel 6.12 LTS, PipeWire 1.4, Mesa 24).
#
# The desktop is built from the vendored monorepo under <repo>/desktop/.
# install.sh runs `just build` + `just install` against that tree to put the
# binaries / .desktop / systemd unit files into the rootfs, then wires up
# the greeter / display manager / user services so the system boots into a
# graphical login.

# Qt frontends + /etc/environment exports handle legacy apps.

# --- GUI automation (AI agent driving the desktop) ---
# wtype: Wayland-native, uses wlr-virtual-keyboard-v1 (cosmic-comp
# supports it). Good for typing into focused windows.
# ydotool: low-level libevdev / uinput; works regardless of compositor
# protocol support but needs the ydotoold system service running. We
# enable that unit in rootfs/features/systemd/install.sh.
wtype
ydotool

# --- Time sync (silent NTP via systemd-timesyncd) ---
# systemd-timesyncd is part of the systemd binary package but in
# trixie ships separately. Enabled (started at boot) by
# rootfs/features/systemd/install.sh.
systemd-timesyncd

# --- Removable media / storage (real hardware fundamentals) ---
# udisks2: D-Bus API the desktop uses to mount/unmount USB sticks
# and external disks. Without it, plugging a USB stick into a
# real laptop does literally nothing (cosmic-files won't see it).
# The polkit rule shipped in 40-clawos.rules lets active sudo
# users drive it without password prompts.
udisks2
# Mount Windows / Mac USB drives. The vast majority of USB sticks
# sold today are formatted exFAT or NTFS, not ext4. Without these
# the user plugs in a stick and gets "filesystem not supported".
ntfs-3g
exfatprogs
# gvfs: GIO Virtual Filesystem. cosmic-files is built with the
# `gvfs` feature on (desktop/files/Cargo.toml), so it depends on
# this at runtime for: the trash, mount-monitoring, network
# locations, archive:// scheme. gvfs-backends adds smb / sftp /
# afp / dav / mtp / gphoto2 transports. gvfs-fuse exposes mounts
# under /run/user/$UID/gvfs so non-GIO apps (CLI tools, terminal
# etc.) can also see them as plain paths.
gvfs
gvfs-backends
gvfs-fuse

# --- Firmware updates (LVFS) ---
# fwupd talks to the Linux Vendor Firmware Service and applies
# UEFI / BIOS / dock / SSD / Thunderbolt firmware updates the same
# way Windows Update does on Windows. Without it, laptops sit on
# vendor firmware from 2021 forever and accumulate CVEs. The
# fwupd-refresh.timer is enabled by rootfs/features/systemd
# (weekly metadata refresh; firmware updates themselves remain
# user-driven).
fwupd

# --- Local-network discovery (mDNS / .local / Bonjour) ---
# avahi-daemon resolves <host>.local and advertises this machine
# so phones, printers and other Macs find it. libnss-mdns plugs
# mDNS into glibc's name resolution stack so every app benefits
# transparently (its postinst patches nsswitch.conf).
avahi-daemon
libnss-mdns

# --- Printing (CUPS + driverless + drivers) ---
# Most users print at some point. cups is the print daemon,
# cups-browsed auto-discovers shared printers on the LAN (works
# hand in hand with avahi), cups-filters has the IPP-Everywhere
# filters for modern driverless printers, printer-driver-all is
# the catch-all metapackage for everything else (HP / Canon /
# Brother / Epson / Lexmark / OKI / Samsung / Xerox / Lexmark /
# Foomatic). Roughly +200MB but pays for itself the first time
# someone double-clicks "Print" on a random office printer.
cups
cups-browsed
cups-filters
printer-driver-all

# --- Thermal management (Intel laptops, no-op elsewhere) ---
# thermald implements Intel's Dynamic Platform Thermal Framework.
# Without it, modern Intel laptops thermal-throttle constantly
# under load and burn through battery fast. Empty on arm64; harmless
# (self-disables) on AMD machines that happen to install it.
${THERMALD_PKG}

# --- Automatic security updates ---
# unattended-upgrades installs Debian security errata in the
# background via apt-daily-upgrade.timer. The actual switch that
# turns it on is /etc/apt/apt.conf.d/20auto-upgrades (shipped in
# overlay/etc/apt/apt.conf.d/).
unattended-upgrades

# --- Location service (auto-timezone, weather, …) ---
# geoclue is the D-Bus location broker. systemd-timedated reads
# from it to set the system timezone automatically; cosmic-applet-
# time and a future weather widget consume the same source. Always
# user-permission-gated; nothing leaks coords without consent.
geoclue-2.0

# --- Fingerprint authentication (laptops) ---
# fprintd is the system fingerprint daemon; libpam-fprintd is the
# PAM module. We enable the PAM stack hook via pam-auth-update from
# rootfs/features/desktop/install.sh. On machines without a reader,
# pam_fprintd returns PAM_IGNORE so password auth falls through
# normally; this is safe to ship by default.
fprintd
libpam-fprintd

# --- Boot splash (Plymouth, themed by the "claw" overlay) ---
plymouth
plymouth-themes

# --- Default user-facing GUI apps ---
# Chromium is the default GUI web browser. It is also the engine the
# `claw-agent-browser` MV3 extension + apps/browser-attached bridge
# attach to when the AI agent needs the user's logged-in session
# (Browser Mode B). Bound to x-scheme-handler/{http,https} and
# text/html in overlay/etc/xdg/mimeapps.list. The headless cos-browser
# CLI (`rootfs/features/browser`) is a separate, AI-only surface and
# does not provide a desktop launcher.
chromium

# Thunderbird is the default mail / news / calendar client. The AI
# Agent's apps/email continues to drive Gmail/Outlook via their HTTPS
# APIs; Thunderbird is the GUI side users open to see their inbox.
# Bound to x-scheme-handler/mailto in overlay/etc/xdg/mimeapps.list.
thunderbird

# --- Default GUI utilities (round-out "normal desktop" baseline) ---
# These fill the everyday-app gaps that COSMIC doesn't ship upstream
# but every normal Linux desktop user expects to be present on first
# boot. All Gtk4 / libadwaita so they sit visually next to the rest of
# the desktop, all packaged in trixie, ~150 MB total.
#
# eog (Eye of GNOME): image viewer. Without it, double-clicking a
# JPG/PNG/GIF/WEBP/BMP/TIFF/SVG in cosmic-files returns "no
# application available". Bound to image/* in mimeapps.list.
# Ships /usr/share/applications/org.gnome.eog.desktop.
eog
# evince: PDF / DjVu / PostScript / TIFF / comic-book reader. Bound
# to application/pdf etc. in mimeapps.list. Ships
# /usr/share/applications/org.gnome.Evince.desktop.
evince
# file-roller: archive manager with GUI extract / create flow for
# zip / tar / gz / bz2 / xz / 7z / rar / iso etc. Also wires up
# the org.gnome.ArchiveManager1 D-Bus service so file managers
# (including cosmic-files via gvfs) can dispatch extraction calls
# to it. Bound to the common archive MIME types in mimeapps.list.
# Ships /usr/share/applications/org.gnome.FileRoller.desktop.
file-roller
# gnome-calculator: GUI calculator with basic / advanced /
# financial / programming modes. Ships
# /usr/share/applications/org.gnome.Calculator.desktop.
gnome-calculator
# gnome-system-monitor: GUI process / CPU / memory / network /
# filesystem viewer — the "Task Manager" most users expect.
# Ships /usr/share/applications/org.gnome.SystemMonitor.desktop.
gnome-system-monitor
# gnome-disk-utility: GUI for partitioning, formatting USB sticks,
# SMART health, image mount / write. cosmic-files only mounts; this
# is the only graphical path to formatting a stick. Ships
# /usr/share/applications/org.gnome.DiskUtility.desktop. Also pulls
# in udisks2 (already in the list above) as the privileged backend.
gnome-disk-utility
# sound-theme-freedesktop: provides the default XDG sound theme
# (/usr/share/sounds/freedesktop/). Without it cosmic-osd volume
# changes, notification arrivals and other libcanberra-driven
# events are silent. Tiny (~700KB) and harmless to ship by default.
sound-theme-freedesktop

# --- Local document full-text search (apps/docs) ---
# Recoll provides the Xapian-backed full-text index and the recollq /
# recollindex / recoll CLIs. apps/docs wraps recollq + recollindex to
# expose docs.search / docs.index / docs.status / docs.configure to the
# AI agent. Defaults to indexing ~/Documents ~/Desktop ~/Downloads
# (see overlay/etc/skel/.recoll/recoll.conf for the seeded user config).
# Real-time monitoring is enabled out of the box via the systemd --user
# unit claw-recoll-index.service (overlay/etc/systemd/user/), which runs
# `recollindex -m` and uses inotify to keep the index current on every
# create / modify / delete.
# Pulls in poppler-utils, antiword, unrtf, etc. as recommends for the
# PDF / Office / RTF format filters.
recoll
