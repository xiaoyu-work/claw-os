# copilot-cli — GitHub Copilot CLI (@github/copilot) installed via npm.
#
# Node.js 24 + bundled npm are installed by the `base` feature from the
# nodesource repo. Listing Debian's `npm` here would conflict because
# trixie's npm (9.2.0) hard-depends on nodejs ≤ 20.x.
#
# No additional packages — install.sh just runs `npm install -g
# @github/copilot` against the existing toolchain.
